# aidenjajo.com

Personal portfolio site for Aiden B. Jajo — data analytics projects, resume, and background.

**Live at:** [aidenjajo.com](https://aidenjajo.com)

## Built with

Plain HTML, CSS, and vanilla JavaScript — no build step or framework. Fonts loaded from Google Fonts (Bricolage Grotesque, Inter).

## Structure

```
index.html              Homepage
projects/                Case studies for each portfolio project
assets/
  css/                  Stylesheets (main.css for the homepage, project.css shared by all project pages)
  js/                   Site behavior (nav, scroll reveal, mobile menu)
  images/               Portraits and project chart images
documents/              Downloadable PDFs (resume, etc.)
```

## Projects

- **Medicare Part D Analysis** — `projects/medicare-part-d.html`
- **Airline Passenger Satisfaction** — `projects/airline-satisfaction.html`
- **Fraud Detection with SMOTE** — `projects/fraud-detection.html`

## Deployment

Hosted on GitHub Pages with a custom domain (see `CNAME`). Pushing to the default branch deploys automatically.
